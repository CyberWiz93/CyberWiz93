# Setting up my Server (Headless)

## 1. Pi Imager

- First thing is first. We will need to set up an micro SD with a raspberry pi OS. 
This can be found here https://www.raspberrypi.com/software/
- Choose your Rasberry device, in this case rasberry pi #3
- Set OS to Ubuntu Server LTS
- Select your device
- Since this is headless, you want to enable ssh 
    - Set up a machine name, user, and password
- Finally insert micro SD into Rasberry pi and power on!
